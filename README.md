# Фінансовий трекер студента

## Мета проєкту
Розробити консольного чат-бота на Python для обліку особистих витрат студента та контролю бюджету.

## Логіка роботи програми

1. При запуску програма зчитує дані з JSON-файлу.
2. Якщо файл не існує — створюється нова структура.
3. Користувач вводить команди.
4. Бот виконує відповідну функцію.
5. Після кожної зміни дані автоматично зберігаються у файл.
6. При додаванні витрати перевіряється перевищення бюджету.

## Структура даних

Дані зберігаються у форматі JSON:

{
    "budget": 5000,
    "expenses": [
        {
            "amount": 200,
            "category": "Їжа",
            "date": "2025-03-01",
            "comment": "Обід"
        }
    ]
}

- budget — встановлений бюджет
- expenses — список словників витрат

## Інструкція запуску

1. Встановити Python 3.
2. Завантажити файл bot.py.
3. У терміналі виконати:
   python bot.py

## Приклад роботи

Введіть команду: встановити бюджет
Введіть суму бюджету: 5000

Введіть команду: додати витрату
Сума: 200
Категорія: Їжа
Дата: 2025-03-01
Коментар: Обід

Введіть команду: залишок
Залишок бюджету: 4800 грн
